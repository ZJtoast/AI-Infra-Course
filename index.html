模块 1

计算与 GPU 编程

01

Transformer 单层计算量与显存分析

从一个 token 的投影追到整层 FLOPs、参数与 KV cache，分别核算 prefill 和 decode。

↗02

GPU 微架构与 Tensor Core

沿线程、warp、SM 与存储层次追踪一次访存，比较各代矩阵指令的参与线程与数据布局。

↗03

CUDA、PTX 与分块算子编程

从手写 PTX 和反汇编读出寻址与寄存器分配，再用矩阵分块解释复用和异步流水。

↗04

Attention 算子与编译执行

逐块推导在线 softmax，追踪前向状态、反向重计算和编译边界。

↗
模块 2

通信与分布式训练

05

集合通信、NCCL 与 RDMA

从四个 rank 的张量归属推导通信量，沿 NCCL、网卡队列和 GPUDirect RDMA 检查传输完成条件。

↗06

训练显存、激活重计算与卸载

画出一次训练更新中参数、梯度、优化器状态和激活的存活区间，找出峰值。

↗07

数据并行、状态分片与训练恢复

从 DDP 梯度归约追到 FSDP 参数收集，再检查分布式检查点能恢复哪些状态。

↗08

多维并行与张量布局

在 TP、SP、CP 和流水线并行之间跟踪一个 microbatch，核对每条边界上的形状和字节数。

↗09

MoE 路由与专家并行

沿 token 分派、专家分组计算与加权汇合追踪数据，区分负载偏斜和网络等待。

↗
模块 3

模型架构与数值方法

10

量化表示、低精度执行与 Muon

核算 scale、权重和临时缓冲，比较训练与推理的精度边界，推导 Muon 的矩阵更新。

↗11

长上下文模型架构与状态复用

比较 MLA、压缩稀疏注意力与递归状态，并沿 DeepSeek-V4.1-Flash 的实际配置追踪模型结构。

↗
模块 4

推理系统

12

推理服务指标与 KV 分页

在同一请求中标出排队、首 token 和后续生成的时间边界，再讨论页分配和批调度。

↗13

推理引擎执行与 CUDA Graph

追踪请求槽位、异步缓冲和采样，并检查 CUDA Graph 重放依赖的地址与生命周期。

↗14

分离式推理与 KV 传输

沿 prefill 到 decode 的交接核算有效字节、重排、传输完成和缓存可见性。

↗15

推测解码与前缀验证

从草稿生成与目标模型验证推导接受概率，比较候选长度、验证代价与端到端时延。

↗
模块 5

训练平台与性能工程

16

智能体强化学习训练系统

沿轨迹采样、奖励、策略更新和权重同步追踪一次训练迭代。

↗17

训练数据管线、检查点与调度

把输入字节换算成有效训练 token，核对预取、持久化与恢复中的状态。

↗18

GPU 性能剖析与瓶颈诊断

先用 Nsight Systems 确定关键路径，再用 Nsight Compute 的 SOL、内存层次和 Roofline 检验算子瓶颈。

↗19

长上下文服务的容量与系统设计

从请求分布和服务目标推导并发、显存与跨机流量，用可复算的条件比较部署方案。
